# Changelog 1.1.0

⚡️ Features:
- Support `types` and `methods` for Telegram Bot API `10.0`
- Add `answer_live_photo`, `answer_paid_media`, `answer_checklist`, `answer_guest_query`, `answer_gift`, `reply_live_photo`, `reply_paid_media`, `reply_checklist`, `stream`, `delete_reaction`, `delete_all_reactions` shortcuts for `MessageCute`
- Add `set_access_settings`, `get_access_settings` shortcuts for `ManagedBotUpdatedCute`
- Add `GuestMessage` view for `guest_message` update

🔧 Fixes:
- Fix bind `bound_api` to cute types
- Fix stopping polling via `.stop` method
- Fix unbound local variable in `Dispatch.__init__` when `waiter_machine`, `middleware_box` parameters were passed
